# DyedBackpacksV2
DyedBackpacksV2 is a [Slimefun5](https://github.com/Slimefun5/Slimefun5/) Addon, originally made by TheBusyBiscuit for Slimefun4 and updated by Phil for Slimefun5.<br>
You need to install Slimefun5 in order for this plugin to work.

DyedBackpacksV2 allows you craft colored variants of the Slimefun5 backpacks using different wools.

**This version was made for java minecraft v26+, I won't maintain it for older versions.**

## Download DyedBackpacksV2
You can download DyedBackpacksV2 right here: [Releases](https://github.com/MaximeBro/DyedBackpacksV2/releases)
